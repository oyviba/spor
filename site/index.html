Follow every branch, including the ones your agents start.

spor is a desktop git client for working alongside coding agents. Each agent task gets its own branch and folder, one inbox tells you which of them needs you, and the history graph shows where all of it went.

Get spor Source on GitHub

spor /spuːr/ n. Norwegian: a track, a trace. What you follow to see where a branch has been.

inbox

What needs me?

Open spor and the first thing you see is one list, across every repository in every workspace. Each row opens where you deal with it, and goes away once you have. Its count is the only badge in the app.

  • An agent waiting on an answer like a plan to approve
  • A finished run you haven't looked at ready for review
  • A failed CI run on your branch with Send failure to agent
  • A pull request waiting for your review from anyone

What's in flight?

A task is a prompt. spor creates agent/<name> from a base branch, checks it out in <repo>.spor/<name> beside your repository, and starts Claude Code (or any command you choose) there. Several agents work at once and none of them touch your checkout.

Read its plan before it changes anything, answer its questions, and steer it while it works. Review the changes with line comments, send them back, or undo a run. When it's right, Land it as one commit, Publish it as a pull request, or Discard it.

The commit graph keeps main pinned to the leftmost lane and colors branches by prefix, so every feat/* shares a hue and agent branches stand apart. Branch labels carry their pull request's number, review state and CI.

Your uncommitted changes sit at the top of the graph. Stage down to single lines, commit, stash, and search by message, author, hash or path:src/main.rs. Right-click to cherry-pick, revert, rebase or Rewrite after here, an interactive rebase you do on screen.

everywhere

Git without the terminal, and without the fear.

Undo instead of “are you sure?”

Staging, discarding, commits, merges, rebases, resets, deleting a branch, landing a task: all happen at once and come back with ⌘Z. Only what git can't take back asks first.

One button to get in step

The branch bar shows Pull, Push, Publish, Pull & push or Force push, whichever fits. Force push is --force-with-lease --force-if-includes.

One conflict banner

A merge or rebase that stops shows on every section. Pick a side per conflict, then Continue, Skip commit or Abort.

GitHub, through gh

Issues, pull requests and Actions: review with line comments, approve, land, read a run's log folded by step, re-run it. Start with agent turns an issue into a task.

Workspaces

Named, colored groups of repositories on the rail, each showing its branch, changed files and what there is to pull.

Everything in ⌘K

Every command, section, work item, branch and repository. Your own shortcuts, unified or side-by-side diffs, and six themes with a live editor.

v0.1.0

Run it on your own repository.

You need Rust, Node 20 or later and pnpm, plus the Tauri prerequisites for your OS. Pull requests, Actions and issues need the GitHub CLI, signed in with gh auth login.

Prefer a Mac app? Grab the Spor-macos artifact from the latest CI run. It isn't signed yet, so open it the first time with right-click → Open.

~/code
# clone and start
git clone https://github.com/oyviba/spor
cd spor/desktop
pnpm install
SPOR_REPO=~/code/your-repo pnpm tauri dev
